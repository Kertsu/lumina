# Lumina 0.1.0-beta.9

Word searches can now be shown to your audience as a summary slide. Use
**Preview summary** in the search results to preview it privately. The slide
shows the search term, number of matching verses, translation, and search scope.

Choose **Send Live** to show the summary. **Restore previous output**
brings back what the audience was seeing before. You can also enable
**Preview search summaries automatically** in Settings.
