# Lumina 0.1.0-beta.8

Lumina switches from shadcn to Astryx. We chose Astryx and its Neutral
theme because the controls and colors feel more at home in the projection
desk.

Workspace tabs have more breathing room, and the last tab no longer shows
a close button. Dialogs use consistent spacing, translation names are
available on hover when clipped, and Bible removal is confirmed directly
below the selected translation. Verse previews and audience slides also
have larger reference and translation labels.
