# Lumina 0.1.0-beta.4

Initial public beta for Bible passage selection and audience projection.

- Find references or search the bundled World English Bible offline.
- Preview passages privately and send them to a separate audience window.
- Keep selections in separate operator workspaces and return through history.
- Receive silent update checks; review and install from the Lumina menu.

This beta is experimental across all platform targets. Compatibility can vary
with the operating system, hardware, and display setup.
The initial installers are not Apple-notarized or Windows publisher-signed.
Read the installation guide and rehearse with your actual displays before a
gathering. Keep backups of important data; do not assume a newer database can
be opened by an older app.

Lumina is free for personal, organizational, and commercial use. Its application
source remains private. Original unmodified installers may be shared with their
license and notices; modified/rebranded builds require permission.
