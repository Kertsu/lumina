## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `Kertsu/lumina` using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five canonical triage labels are used. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo with `GLOSSARY.md` and `docs/adr/` at the root. See `docs/agents/domain.md`.

### Contributing

Follow `CONTRIBUTING.md` for code formatting, implementation branch naming, and commit messages.

### Verification

For features, bug fixes, specs, tickets, and reviews, follow `docs/agents/verification.md`. It overrides skill requirements for automated tests. Save manual verification guides in the main/master checkout, including when working in another worktree.
